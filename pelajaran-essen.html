Objeknya pakai Akkusativ

maskulin: ein → einen

Ich möchte einen Kaffee. — Saya mau secangkir kopi.

feminin: eine → eine (tetap)

Ich möchte eine Pizza. — Saya mau sebuah pizza.

netral: ein → ein (tetap)

Ich möchte ein Wasser. — Saya mau air.

artikel tertentu: der → den, die/das tetap

Du möchtest den Apfel. · Wir möchten die Bücher.
