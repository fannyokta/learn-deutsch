Nama-nama profesi, pertanyaan tentang pekerjaan, dan cara menjawabnya.

❓ Pertanyaan tentang Pekerjaan

Was machst du beruflich?

Apa pekerjaanmu? (informal)

→ Ich bin Lehrer.

Was machen Sie beruflich?

Apa pekerjaan Anda? (formal)

→ Ich bin Ärztin.

Wo arbeitest du?

Di mana kamu bekerja? (informal)

→ Ich arbeite in einer Schule.

Seit wann arbeitest du?

Sejak kapan kamu bekerja?

→ Ich arbeite seit 2020.

📝 Aturan Pembentukan Pekerjaan

👨 Maskulin → 👩 Feminin

  • • Lehrer → Lehrerin (guru)
  • • Arzt → Ärztin (dokter)
  • • Koch → Köchin (koki)
  • • Student → Studentin (mahasiswa)
Aturan: Tambahkan -in untuk bentuk feminin (perhatikan perubahan vokal)

📌 Kata Kerja → Pekerjaan

  • • lehren (mengajar) → Lehrer
  • • arbeiten (bekerja) → Arbeiter (pekerja)
  • • kochen (memasak) → Koch
  • • backen (memanggang) → Bäcker
Aturan: Ambil akar kata kerja + -er (maskulin)

💬 Contoh Kalimat Pekerjaan

Ich bin Lehrer.

Saya seorang guru.

Sie ist Ärztin.

Dia (pr) adalah dokter.

Er arbeitet als Ingenieur.

Dia (lk) bekerja sebagai insinyur.

Ich arbeite in einem Krankenhaus.

Saya bekerja di rumah sakit.

Was sind Sie von Beruf?

Apa profesi Anda? (formal)

Ich möchte Ärztin werden.

Saya ingin menjadi dokter.
